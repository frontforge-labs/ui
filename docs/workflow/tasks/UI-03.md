# UI-03: Packaging, installable from git

- **Repo:** `frontforge-labs/ui`. **Tier:** routine. **Size:** S.
- **Depends on:** UI-02.

## Objective

Make `npm install github:frontforge-labs/ui#<tag>` produce a correct, built package.

## Do

- Move `class-variance-authority`, `clsx` and `tailwind-merge` to `dependencies`; drop
  `tailwindcss` from `dependencies`.
- Make `lucide-react` a peer dependency.
- Fix the exports map so `require.types` points at `./dist/index.d.cts`, and export
  `./package.json`.
- Add `"sideEffects": ["*.css"]`. Export `cn` from `src/index.ts`.
- Add `"prepare": "tsup"` so a git install builds `dist`.
- Add `publint` as a dev dependency and run it in `check` after `build`.

## Done when

`npm run check` (now including publint) exits 0, and a test imports `cn` from `src/index.ts`.

## Out of scope

Tagging a release (Fred does it by hand), component changes.

## Implementer contract

This repo has no `AGENTS.md`, so these are its conventions, taken from its `package.json`, its
configs and `REVIEW.md` on the `review-and-backlog` branch:

- React 19 and TypeScript, built with Vite or tsup; npm with the committed `package-lock.json`;
  Node 24.
- Match the existing style (Prettier defaults as configured, 2-space indent, ES modules).
- Change only what this packet asks. Note follow-ups instead of doing them.
- Install packages with `npm install -D <pkg>` so the lockfile stays in step; never hand-edit it.
- Nothing is pushed. Commit on the task branch only.
