# UI-01: ESLint 9 flat config

- **Repo:** `frontforge-labs/ui`. **Tier:** routine. **Size:** S (under 100 changed lines,
  excluding files deleted outright and `package-lock.json`).
- **Depends on:** nothing.

## Objective

`npm run lint` cannot run today: there is no `eslint.config.js`, ESLint 9 ignores the
`eslintConfig` key in `package.json`, and the `lint` script uses `--ext`, which flat config
removed. Make lint run and pass.

## Do

- Add `eslint.config.js` (flat config) with `@eslint/js`, typescript-eslint (recommended),
  eslint-plugin-react-hooks, eslint-plugin-jsx-a11y, eslint-plugin-storybook and
  eslint-config-prettier. Ignore `dist` and `storybook-static`.
- Remove the `eslintConfig` key from `package.json` and set `"lint": "eslint ."`.
- Delete the `/stories` template folder (the untouched Storybook template; `.storybook/main.ts`
  only globs `src`).
- Fix, or narrowly disable with a one-line reason, the errors that surface. Leave jsx-a11y hits
  in the overlay components (Modal, Drawer, Popover, Tooltip, Tabs, Accordion, Switch, Checkbox,
  RadioGroup) as warnings: UI-06 to UI-09 fix them.

## Done when

- `npm run lint` exits 0.
- `npx tsc --noEmit` reports no new errors compared with the base.

## Out of scope

Vitest, typecheck and check scripts (UI-02), packaging (UI-03), any component behaviour change.
